# Когортный отчёт

Запуск запросов: `python3 src/sqlmd.py reports/02_cohort_report.md`. Адрес ячейки записывай так: когорта `2026-07-15`, столбец `d7`.

### 1. Что бросается в глаза

Не меньше четырёх находок в абсолютных числах.

Контрольный вопрос: что в твоих находках видно прямо в отчёте, а что — твоя догадка о причине?

**Ответ:** В отчете прямо видны числа (размер когорт, d1, пустые ячейки, провалы по диагонали); причины (событие, сбой) - моя догадка. Находки 2,3 и 4 подтверждены другими таблицами (users,act,activity); что именно было 7 августа, в данных не видно.

```sql
SELECT signup_date, COUNT(*) AS registered FROM users WHERE signup_date BETWEEN '2026-08-05' AND '2026-08-17' OR signup_date BETWEEN '2026-08-26' AND '2026-09-03' GROUP BY signup_date ORDER BY signup_date;
SELECT MAX(date) AS last_day FROM activity;
SELECT COUNT(d1) AS filled_d1, COUNT(d7) AS filled_d7, COUNT(d30) AS filled_d30, COUNT(*) AS cohorts FROM cohorts;
```

### 2. Удержание в процентах

Контрольный вопрос: какая когорта лучшая в штуках и какая — в процентах? Почему картина поменялась?

**Ответ:**  В штуках лучшая когорта 2026-08-08: d1 = 351, d7 = 144, d30 = 49. В процентах лучшие другие, маленькие: d1 — 2026-09-11 (58,5%), d7 — 2026-09-18 (31,3%), d30 — 2026-07-24 (17,6%). 2026-08-08 — самая большая когорта (1624 человека): даже при удержании 21,6% / 8,9% / 3,0% она даёт больше людей, чем обычная когорта в 120–160 человек с 45% / 25% / 15%. Штуки зависят от размера когорты, проценты — от липкости новичков.

```sql
SELECT cohort, d0, d1, d7, d30,
       ROUND(d1 * 100.0 / d0, 1) AS r1_pct,
       ROUND(d7 * 100.0 / d0, 1) AS r7_pct,
       ROUND(d30 * 100.0 / d0, 1) AS r30_pct
FROM cohorts
ORDER BY cohort;
SELECT cohort, d0, d1, d7, d30 FROM cohorts ORDER BY d1 DESC LIMIT 3;
SELECT cohort, d0, d1, ROUND(d1 * 100.0 / d0, 1) AS r1_pct FROM cohorts WHERE d1 IS NOT NULL ORDER BY d1 * 1.0 / d0 DESC LIMIT 3;
SELECT cohort, d0, d7, ROUND(d7 * 100.0 / d0, 1) AS r7_pct FROM cohorts WHERE d7 IS NOT NULL ORDER BY d7 * 1.0 / d0 DESC LIMIT 3;
SELECT cohort, d0, d30, ROUND(d30 * 100.0 / d0, 1) AS r30_pct FROM cohorts WHERE d30 IS NOT NULL ORDER BY d30 * 1.0 / d0 DESC LIMIT 3;
```

Контрольный вопрос: почему границы проходят именно там? Удержание периода можно посчитать от сумм или как среднее процентов когорт — какой способ ты выбрал и насколько отличаются числа? По скольким когортам посчитано удержание дня 7 и дня 30?

**Ответ:** Волна — когорта больше обычной вдвое: средний размер когорты до 06.08 равен 129,4, порог 2 × 129,4 ≈ 259; выше порога ровно 15 когорт (07–16.08 и 28.08–01.09). Отсюда границы периодов. Удержание посчитано от сумм: каждый человек считается один раз, а среднее процентов даёт когорте в 130 человек тот же вес, что когорте в 1600. d1 посчитан по 89 когортам, d7 — по 83, d30 — по 60; в периоде E d30 нет, в D — только по двум когортам. Искажены три ячейки из-за 19 августа: 2026-08-18/d1, 2026-08-12/d7, 2026-07-20/d30.

```sql
SELECT ROUND(AVG(d0), 1) AS avg_d0_before, ROUND(2 * AVG(d0)) AS threshold FROM cohorts WHERE cohort <= '2026-08-06';
SELECT cohort, d0 FROM cohorts WHERE d0 > 259 ORDER BY cohort;
SELECT CASE WHEN cohort <= '2026-08-06' THEN 'A 01.07-06.08'
            WHEN cohort <= '2026-08-16' THEN 'B 07.08-16.08'
            WHEN cohort <= '2026-08-27' THEN 'C 17.08-27.08'
            WHEN cohort <= '2026-09-01' THEN 'D 28.08-01.09'
            ELSE 'E 02.09-28.09' END AS period,
       COUNT(*) AS cohorts,
       SUM(d0) AS newcomers,
       ROUND(SUM(d1) * 100.0 / SUM(CASE WHEN d1 IS NOT NULL THEN d0 END), 1) AS r1_pct,
       ROUND(SUM(d7) * 100.0 / SUM(CASE WHEN d7 IS NOT NULL THEN d0 END), 1) AS r7_pct,
       ROUND(SUM(d30) * 100.0 / SUM(CASE WHEN d30 IS NOT NULL THEN d0 END), 1) AS r30_pct,
       COUNT(d1) AS n_d1, COUNT(d7) AS n_d7, COUNT(d30) AS n_d30
FROM cohorts
GROUP BY period
ORDER BY period;
SELECT CASE WHEN cohort <= '2026-08-06' THEN 'A 01.07-06.08'
            WHEN cohort <= '2026-08-16' THEN 'B 07.08-16.08'
            WHEN cohort <= '2026-08-27' THEN 'C 17.08-27.08'
            WHEN cohort <= '2026-09-01' THEN 'D 28.08-01.09'
            ELSE 'E 02.09-28.09' END AS period,
       ROUND(AVG(d1 * 100.0 / d0), 1) AS avg_r1_pct,
       ROUND(AVG(d7 * 100.0 / d0), 1) AS avg_r7_pct,
       ROUND(AVG(d30 * 100.0 / d0), 1) AS avg_r30_pct
FROM cohorts
GROUP BY period
ORDER BY period;
```

### 4. Самая странная находка

Какая календарная дата за ней стоит? Подтверди другим источником — запросом не к таблице `cohorts`.

Контрольный вопрос: это случилось только с новичками или со всеми? Какие числа удержания из-за этого нельзя брать как есть?

**Ответ:** Дата — 2026-08-19 (среда). По таблице act: DAU 19 августа = 935 против 2475 (18.08) и 2542 (20.08); старых пользователей активно 341 против 992 и 1045, то есть упало у всех, не только у новичков. Независимая проверка когорты 18 августа без cohorts: на следующий день заходили 19 человек, как в отчёте. Нельзя брать как есть: d1 когорты 2026-08-18, d7 когорты 2026-08-12, d30 когорты 2026-07-20. Причина в данных не видна (догадка — сбой на сайте).

```sql
SELECT date, COUNT(DISTINCT user_id) AS dau,
       COUNT(DISTINCT CASE WHEN signup_date < '2026-07-01' THEN user_id END) AS old_users
FROM act
WHERE date BETWEEN '2026-08-16' AND '2026-08-22'
GROUP BY date
ORDER BY date;
SELECT COUNT(*) AS d0, SUM(back_d1) AS d1 FROM newcomers WHERE signup_date = '2026-08-18';
SELECT COUNT(DISTINCT user_id) AS d1_from_act FROM act WHERE signup_date = '2026-08-18' AND day_n = 1;
```

## Вывод

Какие новички уходят и когда? Отличаются ли они от остальных новичков? С числами.
**Ответ:**  Уходят в первую очередь новички из двух волн: 15 когорт дали 10 420 новичков из 20 907 (49,8%); из них на следующий день вернулись 21,8%, через неделю — 9,4%, через 30 дней — 3,6%. У остальных 10 487 новичков: 39,6% / 22,8% / 10,9%. Но и обычные новички уходят сразу: 60% не возвращаются на следующий день.
```sql
SELECT CASE WHEN cohort BETWEEN '2026-08-07' AND '2026-08-16' OR cohort BETWEEN '2026-08-28' AND '2026-09-01' THEN 'волны' ELSE 'остальные' END AS grp,
       COUNT(*) AS cohorts,
       SUM(d0) AS newcomers,
       ROUND(SUM(d1) * 100.0 / SUM(CASE WHEN d1 IS NOT NULL THEN d0 END), 1) AS r1_pct,
       ROUND(SUM(d7) * 100.0 / SUM(CASE WHEN d7 IS NOT NULL THEN d0 END), 1) AS r7_pct,
       ROUND(SUM(d30) * 100.0 / SUM(CASE WHEN d30 IS NOT NULL THEN d0 END), 1) AS r30_pct
FROM cohorts
GROUP BY grp;
SELECT SUM(d0) AS all_newcomers FROM cohorts;
```
